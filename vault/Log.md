# Log

One file per person: `Log/<handle>.md`. Only you and your AI agent write in yours, so it never conflicts.

- Start your file with the line `Up: [[Log]]`, so it joins this hub in the graph.
- Add an entry when you finish a work block, using the [[Session Log]] template. Newest at the bottom.

The log is what lets a teammate pick up your work while you sleep, and the "AI used for" lines become the AI section of Credits.

[[Sync notes]] holds the check-in notes and belongs to the coordinator.
