# Submission Checklist

Go through this together on the Sun 20:00 call. One person shares their screen and ticks, the other two check. Owner: Product and story lead.

Target: a **first version at Sun 18:00 CET**, the **final version at 21:00 CET**. Resubmitting is allowed and judges see the latest version. Hard deadline Mon 05:59 CET (Sun 23:59 ET). Late submissions are not accepted. If the upload fails at the deadline, email contact@veritasai.com at once with the links.

A submission is complete once it has **working links to both code and write-up**.

## 1. Code
- [ ] Everyone has run `git sync` and has nothing left unpushed on their computer
- [ ] Repo is **public** (Settings → General → Danger Zone → Change visibility) and opens in a private browser window
- [ ] `notebooks/main.ipynb` runs top to bottom from a fresh clone (the fresh-run test in Notebook Workflow)
- [ ] It is **saved with its outputs visible**, so judges see results without running it
- [ ] The README links to `notebooks/main.ipynb` and its "Run it" steps work
- [ ] README says in five lines what it is and how to run it, and the placeholder comments are gone
- [ ] No full names, school, phone numbers, emails, private links or secrets anywhere in the repo: check notebook outputs and search `vault/`
- [ ] `main` is green: the latest code commit on GitHub has a ✓
- [ ] Every line of project code (`notebooks/`, `src/`, `tests/`) was written after Sat 06:00 CET. Commits from before that are docs and config only

## 2. Write-up
- [ ] One page, in the official template. See [[Write-up]]
- [ ] Problem, what we built, **what we added**, how it works, results vs baseline with failures and results by group, next steps, sources
- [ ] It answers the four questions: who it's for, what goes in and out, does it beat the baseline, where it fails
- [ ] The track's must-haves are met (see Track Briefs)
- [ ] Lists the AI tools we used, and says what we learned
- [ ] Health track: contains *"This project is a prototype and is not medical advice."* Finance track: *"This project is a prototype and is not financial advice."*
- [ ] The numbers match Evaluation exactly
- [ ] Credits for datasets, models and libraries, copied from Credits
- [ ] Read aloud once by someone who didn't write it
- [ ] No names or school
- [ ] Exported in the format the submission form asks for (Obsidian: File → Export to PDF)

## 3. Video (optional, recommended)
- [ ] 2:00 or under. Check the exact length of the final file
- [ ] Follows [[Demo Script]]: problem, real input to result, data + model + baseline, one limitation
- [ ] The screen text is readable at 720p, the voice is clear
- [ ] No names, school, or faces
- [ ] Uploaded as **unlisted** on YouTube (or on Drive, shared with anyone who has the link), and the link plays in a private browser window

## 4. Submit
One person submits for the whole team. Form link: pinned in the WhatsApp group.
- [ ] Project title, team name, "team"
- [ ] Every member's **name, email and school**, spelled right
- [ ] Track
- [ ] Starting point: the suggested project we started from, or "Our own idea"
- [ ] One-sentence pitch: *"Our project helps [a specific person] by taking [an input] and giving back [an output]."*
- [ ] Code link, write-up link, video link. Each one opened in a private window first
- [ ] What we added (our own user, data or question)
- [ ] Datasets, models and AI tools used, with links (from Credits)
- [ ] New to AI? Answered
- [ ] Submitted by: ______ at: ______
- [ ] Confirmation screenshot posted in the WhatsApp group (not in the repo: we don't push after the final submission)

## 5. After
- [ ] Don't push to the repo after submitting, at least until finalists are announced on Wed 18 Nov
- [ ] Each person writes three lines in their log: what worked, what didn't, what next time
- [ ] If we're finalists: rehearse the 5-minute demo and the Q&A list in Rubric
